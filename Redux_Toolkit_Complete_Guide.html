1. Frontend UI Diagnosis & Why It Did Not Show

If you visited the site and saw a blank page, connection failure, or missing interactive elements, here were the exact root causes and how they have been fixed:

Problem 1 IPv6 vs. IPv4 Host Binding in Vite

Vite 8 binds by default to [::1]:5173 (IPv6 loopback). In many Windows browsers, typing http://localhost:5173 or http://127.0.0.1:5173 queries the IPv4 stack first, resulting in "Site can't be reached".

Solution Applied

Configured server: { host: true, port: 5173 } in vite.config.ts so the server listens on all network interfaces (0.0.0.0 and ::).

Problem 2 Ephemeral Auth State (Disappearing on Refresh)

The authSlice initialized user: null, accessToken: null, isAuthenticated: false solely in memory. Refreshing any page immediately discarded the logged-in state.

Solution Applied

Updated authSlice.ts to safely read initial values from localStorage and write tokens/user data upon login (and clear on logout).

Problem 3 Missing Axios Authorization Bearer Token

Axios in src/lib/api.ts did not attach the JWT bearer token to outgoing HTTP requests.

Solution Applied

Added an Axios request interceptor that automatically retrieves accessToken from localStorage and attaches Authorization: Bearer <token>.

Problem 4 Missing Typed Hooks & Navbar Auth Controls

Components imported untyped useDispatch, and the Navbar did not show user profiles or Login/Logout buttons, giving the appearance of a static or disconnected interface.

Solution Applied

Created src/store/hooks.ts with useAppDispatch and useAppSelector, and connected Navbar.tsx to display live user name, Login, and Logout actions.

2. What is Redux Toolkit (RTK)?

Redux Toolkit (RTK) is the official, standardized way to write Redux logic. Classic Redux required writing separate action types, action creators, reducers, and immutability handlers (e.g. spread operators { ...state, ... }). RTK simplifies this completely.

[ React Component / UI ]
│ (1. Dispatches action)
▼
[ Redux Store: configureStore ]
│ (2. Forwards to Reducers)
▼
[ Slices: createSlice (authSlice / uiSlice) ]
│ (3. State updated via Immer safely)
▼
[ useAppSelector Hook ] ──► (4. Re-renders Component with fresh state)

Why Redux Toolkit is Superior:

  • Zero Immutability Headaches: Powered by Immer, you write simple assignments like state.user = action.payload, and Immer converts them into safe immutable copies under the hood.
  • All-in-One Slices: Action types, action creators, and reducers are defined together in one single call with createSlice().
  • Redux DevTools & Thunk Pre-configured: Out of the box, DevTools and async middleware are ready without extra configuration.
  • First-class TypeScript Support: Full type safety for your state, dispatch, and actions.

3. Step-by-Step Code Walkthrough in AgFarm

Step 1: Create a Slice (src/store/slices/authSlice.ts)

import { createSlice, type PayloadAction } from '@reduxjs/toolkit'
import type { AuthUser } from '@/services/auth.service'

interface AuthState {
  user: AuthUser | null
  accessToken: string | null
  isAuthenticated: boolean
  isLoading: boolean
  error: string | null
}

const storedToken = typeof window !== 'undefined' ? localStorage.getItem('accessToken') : null
const storedUserStr = typeof window !== 'undefined' ? localStorage.getItem('authUser') : null

const initialState: AuthState = {
  user: storedUserStr ? JSON.parse(storedUserStr) : null,
  accessToken: storedToken,
  isAuthenticated: Boolean(storedToken),
  isLoading: false,
  error: null,
}

export const authSlice = createSlice({
  name: 'auth',
  initialState,
  reducers: {
    setCredentials(state, action: PayloadAction<{ user: AuthUser; accessToken: string }>) {
      state.user = action.payload.user
      state.accessToken = action.payload.accessToken
      state.isAuthenticated = true
      state.error = null

      localStorage.setItem('accessToken', action.payload.accessToken)
      localStorage.setItem('authUser', JSON.stringify(action.payload.user))
    },
    clearCredentials(state) {
      state.user = null
      state.accessToken = null
      state.isAuthenticated = false
      state.error = null

      localStorage.removeItem('accessToken')
      localStorage.removeItem('authUser')
    },
    setAuthLoading(state, action: PayloadAction) {
      state.isLoading = action.payload
    },
    setAuthError(state, action: PayloadAction) {
      state.error = action.payload
      state.isLoading = false
    },
  },
})

export const { setCredentials, clearCredentials, setAuthLoading, setAuthError } = authSlice.actions
export default authSlice.reducer

Step 2: Configure the Central Store (src/store/store.ts)

import { configureStore } from '@reduxjs/toolkit'
import uiSlice from './slices/uiSlice'
import authSlice from './slices/authSlice'

export const store = configureStore({
  reducer: {
    ui: uiSlice,
    auth: authSlice,
  },
})

// Infer the RootState and AppDispatch types from the store itself
export type RootState = ReturnType<typeof store.getState>
export type AppDispatch = typeof store.dispatch

Step 3: Define Typed Custom Hooks (src/store/hooks.ts)

Using useAppDispatch and useAppSelector provides immediate TypeScript autocompletion and prevents state type errors across your entire application:

import { useDispatch, useSelector } from 'react-redux'
import type { AppDispatch, RootState } from './store'

export const useAppDispatch = useDispatch.withTypes<AppDispatch>()
export const useAppSelector = useSelector.withTypes<RootState>()

Step 4: Provide Store to React App (src/main.tsx)

import { Provider as ReduxProvider } from 'react-redux'
import { store } from '@/store/store'

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <ReduxProvider store={store}>
      <App />
    </ReduxProvider>
  </StrictMode>
)

Step 5: Consuming State and Dispatching in Components (Navbar.tsx)

import { useAppDispatch, useAppSelector, clearCredentials, openConsultationModal } from '@/store'

export function Navbar() {
  const dispatch = useAppDispatch()
  
  // 1. Read state cleanly with TypeScript types automatically inferred
  const { user, isAuthenticated } = useAppSelector((state) => state.auth)
  const isModalOpen = useAppSelector((state) => state.ui.consultationModalOpen)

  // 2. Dispatch actions
  const handleLogout = () => {
    dispatch(clearCredentials())
  }

  return (
    <nav>
      {isAuthenticated ? (
        <div>
          <span>Hello, {user?.fullname}</span>
          <button onClick={handleLogout}>Logout</button>
        </div>
      ) : (
        <a href="/login">Sign In</a>
      )}
      <button onClick={() => dispatch(openConsultationModal())}>Book Consultation</button>
    </nav>
  )
}
